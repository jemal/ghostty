Pane motion: the buttons in a pane header split right, split down, zoom and close, and Alt+D (split right), Alt+E (split down), Alt+Z and Alt+W do the same for the focused pane. During the motion the pane content stretches, because in GTK it will be a picture of the terminal; the real terminal takes its final size when the motion ends. 0 ms turns the motion off. Rex marks the focused pane only by dimming the other panes; “Dim” sets how visible the other panes stay. Vertical mode has no top bar. The sidebar button (in the side list, or at the left of the first pane header) and Ctrl+Shift+B show or hide the side list. The ⌘ button opens the command palette: type to filter, ↑ ↓ to move, Enter or Escape to close. Click a tab or a pane to select it. The tab shows the app icon, then one bar for each pane in the tab (a green bar is the focused pane). Long tab labels fade out instead of showing “…”. A dot is the existing attention marker; hover shows the close button. The pane buttons are split right, split down, zoom and close; zoom works in this draft. Rex's eye button is not included because Ghostty has no matching action.

Path picker: Super+I (or “Insert Path…” in the command palette, or the button above) opens a card at the cursor of the focused pane. The search box starts with the pane's folder. The list shows the files and folders in the typed folder, one level at a time; hidden files show when you type a “.”. Rows with a clock are recent paths: folders that a pane was in (from OSC 7) and paths picked here before. Above the cursor, the best match is at the bottom, next to the search box; with no room above, the card opens below and the order turns over. Type to filter (the letters in order, not next to each other), ↑ ↓ to move, Tab to go into a folder, Shift+Tab to go up one folder, Enter to put the path at the cursor, Escape to close. Super+I opens the card in every pane, for example after “:e ” in hx. Super+I again closes it. A path inside the pane's folder is put in relative to it. At a shell prompt, a name that starts with “-” gets “./” in front and special characters are quoted; in other programs (hx, claude, codex) the path is plain text. A space is added when the cursor is right after other text. Typing “~/” or “/” after a folder starts the path again. When fewer than 3 rows fit in the pane, the card opens in the middle of the window. A path with a space or another special character is put in single quotes, with the full home folder in place of “~” (try Downloads › Screenshot 2026-10-26.png).
